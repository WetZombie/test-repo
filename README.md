## 项目介绍 📦

这是一个基于 STM32L031 的 LED 闪烁项目，使用 Keil MDK-ARM 开发。

### 功能特性：
- ✅ 炫酷的 LED 呼吸灯效果
- ✅ 彩虹循环变色
- ✅ 多种状态指示灯
- ✅ 软件 PWM 亮度调节

## 开发环境 💻

- **MCU**: STM32L031
- **IDE**: Keil MDK-ARM
- **库**: STM32L0xx LL 库
- **开发工具**: Trae IDE
